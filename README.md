# klijentske-web-aplikacije-25
Ovaj repozitorijum sadrzi izvorni kod Angular 19 aplikacije za repretoar filmova

## Technologies Used

- Angular 20.3.6
- TypeScript
- Node.js
- npm
- HTML
- CSS

## Development Server

To start the local development server, run:

```bash
ng serve


Open your browser and navigate to http://localhost:4200/.

The application automatically reloads whenever you modify any source files.
Installation
Clone the repository:
git clone YOUR_REPOSITORY_URL


Navigate to the project directory:
cd InterakcijaCovekRacunar2025


Install dependencies:
npm install


Building
To build the project, run:
ng build


The build artifacts will be stored in the dist/ directory.
Running Unit Tests
ng test
